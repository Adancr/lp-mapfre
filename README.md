# Mapfre Peru Funeral Services Landing Page

## Description

This project is a landing page for Mapfre's funeral services in Peru. It provides users with information and choices regarding two main services:

*   **CAMPOSANTO MAPFRE:** Cemetery spaces and related services.
*   **SEGURO DE SEPELIO FINISTERRE:** Burial insurance with a complimentary funeral service.

The page aims to guide users to the service that best suits their needs during difficult times.

## Viewing the Page

To view the landing page, open the `index.html` file in a web browser.

## Technologies Used

*   **HTML:** The structure and content of the web page.
*   **CSS:** Styling for the web page, preprocessed using SCSS.
    *   The compiled CSS is located at `dist/css/main.css`.
*   **JavaScript:** While a `dist/js/app.js` file exists, it currently appears to be minimal or unused.

## Project Structure

*   `index.html`: The main HTML file that renders the landing page.
*   `home.html`: Appears to be an unused or placeholder HTML file.
*   `scss/`: Contains the source SCSS files (`main.scss`, `_variables.scss`) for styling. The styles are compiled into `dist/css/main.css`.
*   `dist/`: This directory contains the distributed (compiled/processed) files.
    *   `dist/css/main.css`: The main stylesheet for the landing page.
    *   `dist/js/app.js`: Intended for JavaScript functionalities.
*   `images/`: Contains all images and graphical assets used on the page (e.g., logos, background images).
*   `fonts/`: Contains font files (e.g., Titillium family) used for typography on the page.
*   `README.md`: This file, providing information about the project.
